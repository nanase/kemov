# 公開の API

`/api` のエンドポイントです。公開サイトの各ページが読みます。認証は無く、読むだけです。

どのパスを受けるかは、`worker/src/api/index.ts` が決めます。この文書の表はその写しです。

## 共通の決まり

- 受けるメソッドは GET と HEAD だけ
  - それ以外は 405 で拒む
- 受け持つパスが無ければ、404 と `{"error":"no endpoint at <パス>"}` を返す
- D1 を読むエンドポイントは、答えをエッジのキャッシュに置く
  - D1 が読めないときは、最後に作れた答えを古いと示して返す
  - 応答のヘッダー `x-kemov-cache` と `x-kemov-stale-seconds` が、キャッシュの状態と古さを示す

## D1 を読むエンドポイント

| パス                                    | 返すもの                                                    | クエリパラメーター                                                                            |
| --------------------------------------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `/api/health`                           | 収集のジョブの最後の成功と、バックアップと削除の状態        | なし                                                                                          |
| `/api/live`                             | 配信中と配信予定                                            | なし                                                                                          |
| `/api/channels`                         | メンバーごとの最新の統計と、1 時間・1 日・30 日の増減       | なし                                                                                          |
| `/api/channels/<チャンネル ID>`         | 1 人のメンバーの同じ内容                                    | なし                                                                                          |
| `/api/channels/<チャンネル ID>/videos`  | そのメンバーの動画を新しい順に 1 ページずつ                 | `limit`（既定 50、最大 200）、`cursor`                                                        |
| `/api/channels/<チャンネル ID>/history` | 2 つの時刻のあいだの統計を、区切りごとに 1 つへ間引いたもの | `from`・`to`（既定は直近 7 日、最大 400 日）、`bucket`（`10m`・`hour`・`day`、既定は `hour`） |
| `/api/months`                           | メンバーごとの月ごとの系列と、その合計                      | なし                                                                                          |
| `/api/streams`                          | メンバーごとの配信の時間帯と、直近 5 本の配信               | なし                                                                                          |
| `/api/videos/table`                     | 順位に数える動画すべてを、列ごとの形で                      | なし                                                                                          |
| `/api/videos/ranking`                   | チャンネルをまたいだ順位                                    | `metric`（既定は `viewCount`）、`type`、`limit`（既定 10、最大 100）                          |

`limit` は、読めない値なら既定値に、上限を超えれば上限に置き換えます。`from`・`to`・`bucket`・`metric`・`type` は、読めない値なら 400 で拒みます。

`/api/health` の状態コードは、本文の内容から決まります。削除は 30 日を過ぎたデータの削除のことです（[データ](../data.md#30-日を過ぎたデータの削除)）。

統計（`channel_snapshot`）は 30 日分しかありません。`/history` は最大 400 日を受けますが、30 日より前には何も返しません。30 日の増減は、30 日より最長で約 1 時間 20 分短い間隔で比べます。

`/api/months` の系列は、配信・動画・ショートの本数、配信の秒数、チャットの件数と人数、再生数です。登録者数の系列はありません。`channel_snapshot` が 30 日分しかなく、月ごとの推移を作れないためです。登録者数の長い推移は、[登録者数の節目](#登録者数の節目)から描きます（#225）。

## 画像の中継

| パス                                 | 返すもの           | クエリパラメーター                                                                              |
| ------------------------------------ | ------------------ | ----------------------------------------------------------------------------------------------- |
| `/api/image/channel/<チャンネル ID>` | メンバーのアイコン | `size`（`48`・`88`・`176`、既定は `88`）                                                        |
| `/api/image/video/<動画 ID>`         | 動画のサムネイル   | `size`（`default`・`mqdefault`・`hqdefault`・`sddefault`・`maxresdefault`、既定は `mqdefault`） |

画像は JSON のキャッシュとは別に、ID と大きさごとにキャッシュします。

## 公開用のバケットを返すエンドポイント

| パス                          | 返すもの                                        |
| ----------------------------- | ----------------------------------------------- |
| `/api/footprints/events`      | `kemov-public` の `footprints/events.json`      |
| `/api/genet/music`            | `kemov-public` の `genet/music.json`            |
| `/api/subscribers/milestones` | `kemov-public` の `subscribers/milestones.json` |

どれも、管理サイトが公開したオブジェクトをそのまま返します（[データ](../data.md#公開用のデータ)）。

- 同じバイト列を、オブジェクト自身の `ETag` と `Last-Modified` で返し、読み直さない
- 一度も書いていないキーには、404 と `{"error":"not published yet"}` を返す
- `If-None-Match` には 304 で答える
- HEAD には、GET と同じ状態とヘッダーを、本文無しで返す

### 登録者数の節目

統計ページとメンバーページは、`/api/subscribers/milestones` の節目から登録数の図を描きます（#225）。JSON の形は [管理サイトの API](admin.md#登録者数の節目) にあります。読む側は次のように扱います。

- 404 と `{"error":"not published yet"}` は、節目が 1 件も無いこととして読みます
  - 本文が違う 404 は、失敗として扱います。worker 以外が返した 404 かもしれないためです
- それ以外の失敗は「取得できませんでした」と出し、記録が無い状態と区別します
- 精度が月の節目は、その月の中ほどに置きます
- 人数は、メンバーをまたいで足し合わせません。けもV合計では、メンバーごとの行に節目を並べます
- 図の右端の「いま」の点は `/api/channels` の最新の値です。節目としては保存しません
- メンバーページでは、「月ごと」のパネルの「登録数」のタブに、統計ページでメンバーを選んだときと同じ図を出します。上の欄の登録者数の下には、最新の節目を書きます
