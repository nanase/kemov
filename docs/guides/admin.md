# 管理サイトの使い方

管理サイトの画面に常には出していない説明を、画面ごとにまとめています。各画面の見出しの横にある「ヘルプ」から、その画面の節へ移れます。

画面の作りと API は [管理サイト](../reference/admin.md) にあります。メンバーを増やす・活動を終える手順は [メンバーの増減](members.md) にあります。

## 共通

### 保存と公開

あしあと・登録者数の節目・ジェネット楽曲一覧の行は、下書きと公開中の 2 つの状態を持ちます。

- 下書きの行は「公開」で公開サイトに出る
- 公開中の行は「保存」を押した時点で公開サイトに出る
  - 下書きに戻さずに直せる
  - 公開の条件を満たさない内容は保存できず、本番は前の内容のまま残る
- 公開中の行は削除できない
  - 先に「非公開に戻す」を押して下書きにしてから削除する
- メンバーと配信・動画には下書きが無く、保存した時点で公開サイトに出る

### 本番に反映されていないとき

保存はできたのに、本番の JSON を書けなかったことがあります。このとき編集の欄の上に「保存しましたが本番への反映に失敗しました」「本番に反映されていない変更があります」などと出ます。

- 同じ行をもう一度「公開」「保存」すると、そのときの内容で本番を書き直す
- 一覧の上に「本番に反映」が出ているときは、それを押すと、本番に届いていない変更をまとめて書き出す
- 「非公開に戻す」の後に反映に失敗したときも、一覧の上の「本番に反映」を押す

### まとめて公開

一覧の左の列で行を選ぶと、一覧の下に「まとめて公開」が出ます。選んだ行を 1 行ずつ公開し、終わると、公開できた数・失敗した数と、失敗した行の理由を一覧の下に出します。

### プレビューと仕切り

- 編集の欄の「プレビュー」を押すと、欄の右に公開ページでの見え方が出る
- 一覧と編集の欄の間の仕切りは、ドラッグか上下の矢印キーで動かす
  - ダブルクリックで元の高さに戻る
  - 位置は画面ごとにブラウザが覚える

## あしあと

### 主役

主役は、その出来事が誰のものかを表します。関連メンバーの中から選びます。

- デビューでは本人を選ぶ
- ゲストとして出ただけのメンバーは選ばない
- デビューは、主役を 1 人以上選ばないと公開できない

デビューからの日数と周年は、主役についてだけ数えます。

### 出典の条件

次のどちらかを満たすと、出典の条件を満たします。

- [出典ホワイトリスト](#出典ホワイトリスト) にある URL で始まる出典が 1 つある
- 別々のサイトの出典が 2 つ以上ある

足りないまま公開することはできます。そのとき、公開サイトの年表に「出典の確認待ち」と出ます。

## 登録者数の節目

### 関連する出来事

あしあとの種類が「節目」の出来事から選びます。関連する出来事を変えて保存した後は、一覧の上の「本番に反映」を押してください。

### 出典

出典の条件は、あしあとと同じです（[出典の条件](#出典の条件)）。条件を満たさないと公開できません。

公表者がリスナーのとき、出典の URL は公開サイトに出ません。管理サイトにだけ残ります。

## メンバー

channel_id を書くと、YouTube にそのチャンネルを問い合わせ、名前とアイコンを出します。足す前に、目的のチャンネルで合っているかを確かめてください。channel_id は、保存した後は直せません。

- 「チャンネルが見つかりません」と出たときは、channel_id の誤りを疑う
- 「チャンネルの確認に失敗しました」と出たときは、YouTube への問い合わせが通っていない
  - 「再試行」で問い合わせ直せる

足す手順は [メンバーの増減](members.md#メンバーが増えたとき) にあります。

## 配信と動画の上書き

収集したタイトル・種別・公開状況を、管理サイトから上書きできます。上書きは、公開サイトの次の場所に効きます。

| 上書きする値 | 効く場所                                                           |
| ------------ | ------------------------------------------------------------------ |
| タイトル     | 順位表・メンバーのページ・あしあとなど、タイトルが出るすべての場所 |
| 種別         | どの種類の順位表と月ごとの本数に数えるか                           |
| 公開状況     | 公開以外にすると、公開ページの一覧・順位・月ごとの本数から消える   |

3 つとも外して保存すると、上書きそのものが削除されます。

## 統計

集計から除外した tick は、公開ページの登録者数・再生数と、1 時間・24 時間・30 日の増減に使われません。

いちばん新しい tick を除外すると、公開ページの数は 1 つ前の tick の値になります。

## 出典ホワイトリスト

この一覧にある URL で始まる出典は、1 つだけでも出典の条件を満たします。ほかの出典は、別々のサイトのものが 2 つ以上あれば満たします。

### URL の書き方

- `https://` から書く
- サイト全体を載せるときは、末尾を `/` にする
- 1 つのページや記事だけを載せるときは、そのページの URL をそのまま書く

### 削除したとき

URL を削除しても、既に公開した出来事は公開されたまま残ります。

## 収集の失敗

収集が失敗したまま止まっている対象を並べます。

| ボタン                   | すること                                                                            |
| ------------------------ | ----------------------------------------------------------------------------------- |
| 再取得                   | 次の収集の回で取り直す                                                              |
| 確認済みにする           | 失敗を確認したことにし、また取れるまで一覧から外す                                  |
| 「削除・不明」として処理 | 動画が YouTube から消えたものとして、公開状況を「削除・不明」にし、取り直しをやめる |
