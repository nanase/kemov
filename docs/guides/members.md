# メンバーの増減

メンバーが増えたとき、活動を終えたとき、名前などが変わったときの手順です。操作はどれも、管理サイトのサイドバーの「データ」にある「メンバー」の画面で行います。

| 起きたこと                       | 読む節                                                        |
| -------------------------------- | ------------------------------------------------------------- |
| メンバーが増えた                 | [メンバーが増えたとき](#メンバーが増えたとき)                 |
| メンバーが卒業した・活動を終えた | [メンバーが活動を終えたとき](#メンバーが活動を終えたとき)     |
| 名前・アイコン・リンクが変わった | [名前やアイコンが変わったとき](#名前やアイコンが変わったとき) |

メンバーの仕組み（誰がどの列を書くか、入力の規則、表示順）は [データ](../reference/data.md#メンバー) にあります。

## 共通のこと

- 保存した時点で公開サイトに効く
  - あしあとのような公開の操作は必要ない
- 公開サイトに出るまで、最長で 2 分ほどかかる
  - 公開の API が応答を 1 分キャッシュし、ブラウザも 1 分キャッシュするため
- 保存はすべて版の履歴に残る
  - サイドバーの「運用」にある「版の履歴」で、entity を「メンバー」に絞って見られる
- 保存できないときは、編集の欄の上に「保存できません」の帯が出る
  - 帯には、どの欄の何が規則に合わないかが英語で出る
  - 規則は [足すときの規則](../reference/data.md#足すときの規則) にある

## メンバーが増えたとき

### 足す

1. ツールバーの「＋ メンバーを足す」を押す
2. 右の欄に、次の表のとおり書く
3. 「一覧に足す」を押す
4. 足したメンバーが一覧の末尾に「未保存」の印つきで並ぶので、各行の「↑」「↓」で望む位置へ動かす
5. ツールバーの「保存」を押す

| 欄         | 書くもの                                                         | 省略     |
| ---------- | ---------------------------------------------------------------- | -------- |
| channel_id | YouTube のチャンネル ID。`UC` で始まる 24 文字                   | できない |
| 名前       | サイトの各ページに出る名前                                       | できない |
| fullname   | 日本語と英語を並べた名前。例: `ジェネット / Large-spotted Genet` | できない |
| globalname | 英語の名前。例: `Large-spotted Genet`                            | できる   |
| twitter    | X のハンドル。`@` は付けない                                     | できる   |
| twitch     | Twitch のログイン名                                              | できる   |
| 活動開始   | 活動を始めた日。`YYYY-MM-DD`                                     | できない |
| 活動終了   | 空欄のままにする。空欄は活動中を表す                             | できる   |
| 色         | key・sub・light・back の 4 つ。どれも `#RRGGBB`                  | できない |

channel_id は、保存した後は直せません。YouTube のチャンネルのページで確かめてから書いてください。

並び順は運用者が決めます。活動開始日などから自動では決まりません。

「保存」を押すまで、足した行と動かした順番は画面の中にだけあります。

- ほかの画面へ移って戻っても残る
- タブを閉じる・再読み込みすると消える
  - 消える前に、ブラウザが確認を出す
- 「元に戻す」を押すと、保存していない変更をすべて捨てる

途中で別の人がメンバーを足したり消したりしていると、「保存」で「メンバー情報に変更がありました。再読み込みしてください」と出ます。ツールバーの「再読み込み」を押してから、もう一度「保存」を押します。保存していない変更は、再読み込みしても残ります。

### 収集が始まったことを確かめる

収集は 10 分ごとに `channel` の全員を読みます。保存した後の最初の回から、足したメンバーも読みます。

1. 10 分ほど待つ
2. サイドバーの「データ」にある「統計」を開く
3. ツールバーの選択で、足したメンバーを選ぶ
4. 今日の日付の行があり、「tick」の数が 10 分ごとに増えることを確かめる

あわせて、サイドバーの「やること」にある「収集の失敗」に、そのメンバーの「チャンネル統計」や「動画の一覧取得」が出ていないことを確かめます。出ているときは、channel_id が実在するチャンネルのものかを確かめてください。

### 公開サイトで確かめる

- 統計（`/stats/`）の一覧に並ぶ
- メンバーのページ（`/members/<チャンネル ID>`）が開ける
- あしあと（`/`）に、活動開始日から線が描かれる
  - 活動開始日が今日より後なら、その日まで線は描かれない

最初の収集が終わるまで、アイコンの代わりに、メンバーの色の円と名前の 1 文字目が出ます。

デビューをあしあとの出来事として載せるときは、あしあとの画面で別に足し、公開の画面から公開します（[管理サイト](../reference/admin.md#画面)）。

### 足しても取れないもの

- 動画は、そのチャンネルの新しいほうから 50 本までしか取らない
  - 収集は、アップロードの一覧の最初の 1 ページだけを読む
  - 過去の動画が 50 本を超えるチャンネルを足すと、それより古い動画は入らない（[#230](https://github.com/nanase/kemov/issues/230)）

メンバーが 1 人増えると、YouTube Data API のクォータを 1 日 144 units 多く使います（[YouTube Data API のクォータ](../reference/architecture.md#youtube-data-api-のクォータ)）。

## メンバーが活動を終えたとき

活動を終えたメンバーは消さずに、活動終了日を書きます。活動していたころの記録は、そのまま公開サイトに残ります。

### 活動終了日を書く

1. 一覧で、そのメンバーの行を選ぶ
2. 「活動終了」の欄に、活動した最後の日を `YYYY-MM-DD` で書く
3. 編集の欄の下の「保存」を押す

保存すると、編集の欄の見出しの印が「活動中」から「活動終了」に変わり、一覧の「活動終了」の列に日付が出ます。

- 活動開始日より前の日付は保存できない
- 活動中に戻すときは、「活動終了」の欄を空にして保存する

### 公開サイトでの見え方

活動を終えたメンバーも、一覧と集計に含めます。

| ページ                                 | 見え方                                                                 |
| -------------------------------------- | ---------------------------------------------------------------------- |
| 統計（`/stats/`）                      | 一覧と合計に含む。一覧の色の帯と、メンバーの欄の上端の線が点線になる   |
| メンバー（`/members/<チャンネル ID>`） | 活動期間が「開始日 → 終了日」になり、点線の枠で囲む                    |
| あしあと（`/`）                        | 線が活動終了日で止まり、端に横棒が付く。線は活動中のメンバーと同じ実線 |

統計には「活動中のメンバーだけ表示」の切り替えがあり、既定では活動を終えたメンバーも表示します。

- 合計の登録者数は、活動を終えたメンバーの最後の値を数え続ける
- 登録者数の推移は、絞り方にかかわらず合計では足し合わせない。けもV合計の記録パネルの「登録数」は、メンバーごとの行に節目を並べる（#225）
- 一覧の「登録数」の小さな棒は、活動終了日より後の月を出さない
- メンバーのページの期間ごとの集計は、活動終了日の翌日からさかのぼって数える

卒業をあしあとの出来事として載せるときは、種類を「卒業・活動終了」にして、あしあとの画面で別に足し、公開します。

活動を終えても、`channel` に行がある限り、収集は 10 分ごとにそのチャンネルを読み続けます。

### チャンネルが無くなったとき

YouTube がチャンネルを返さなくなると、収集の失敗の画面に、そのメンバーの「チャンネル統計」や「動画の一覧取得」が出ます。「確認済みにする」を押すと、また取れるまで一覧から外れます。

統計と取れなくなった動画は、30 日で消えます（[30 日を過ぎたデータの削除](../reference/data.md#30-日を過ぎたデータの削除)）。あしあとの出来事や登録者数の節目も無いメンバーは、そこで削除できる状態になります。それでも消さずに、活動終了日で扱います。

## メンバーを消すとき

消せるのは、次のどれにも記録が無いメンバーだけです。

- 統計（`channel_snapshot`）
- 動画（`video`）
- あしあとの出来事に関わったメンバー（`footprints_event_member`）
- 登録者数の節目（`subscriber_milestone`）

収集は、足した後の最初の回から統計を記録します。そのため、活動していたメンバーはふつう消せません。減ったメンバーは、[活動終了日](#活動終了日を書く) で扱います。

記録があるメンバーの行で「削除」を押すと、「記録があるため削除できません」と出て、何も消えません。

消せたときは、次のことが起きます。

- `channel` の行と、そのメンバーあての収集の予定（`collect_task`）が消える
- 版の履歴に、削除の版が残る
- 公開サイトの一覧から消え、`/members/<チャンネル ID>` は 404 になる

## 名前やアイコンが変わったとき

人が直すものと、収集が YouTube から取り直すものがあります。

| 変わったもの                 | 直し方                                 | 確かめる場所                          |
| ---------------------------- | -------------------------------------- | ------------------------------------- |
| 名前・fullname・globalname   | メンバーの画面で直して「保存」         | 統計の一覧、メンバーのページ          |
| X のハンドル                 | メンバーの画面で直して「保存」         | メンバーのページの X へのリンク       |
| Twitch のログイン名          | メンバーの画面で直して「保存」         | 管理サイトのメンバーの画面            |
| 色                           | メンバーの画面で直して「保存」         | 統計の一覧、あしあとの線              |
| 活動開始日                   | メンバーの画面で直して「保存」         | メンバーのページの活動期間            |
| アイコン                     | 何もしない。収集が 10 分ごとに取り直す | メンバーのページのアイコン            |
| チャンネルの URL（ハンドル） | 何もしない。収集が 10 分ごとに取り直す | メンバーのページの YouTube へのリンク |

- YouTube のチャンネル名が変わっても、サイトの名前は変わらない
  - 収集はチャンネル名を取らないため
  - 名前を合わせるときは、メンバーの画面で直す
- アイコンは、画像の中継が 1 日キャッシュする
  - 新しいアイコンに替わるまで、最長で 1 日かかる
- アイコンとチャンネルの URL は、メンバーの画面に出ない
  - 確かめるときは、公開サイトのメンバーのページを見る

channel_id は直せません。メンバーが別のチャンネルへ移ったとき、記録を新しいチャンネルへ引き継ぐ手段はありません（[#231](https://github.com/nanase/kemov/issues/231)）。
